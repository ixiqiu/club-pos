# 社团收银台（club-pos）

面向学校社团/小摊位的本地收银系统。**Electron** 桌面应用，支持 Windows 与 Linux；
数据全部存在本机，单文件 JSON 备份即可迁移/导入导出，无需联网。

## 功能

- 🧾 **收银**
  - 左侧商品点选、数量增减、搜索与分类筛选
  - 收款方式：**现金**（自动算找零，快捷实收按键）或 **在线**（一键「已在线收款」）
  - 收银时可叠加**临时自定义优惠**（减金额 / 打折 + 备注）
  - **预售登记**（先收款后取货）与 **赊账登记**（先取货后收款）：选中后必须登记购买方 班级 + 姓名 + 备注
  - 完成收银自动打印小票（默认 2 张，可在设置里改份数）
- 🏷️ **商品管理**：增删改、分类、上下架
- 🎁 **优惠管理**：三种规则
  - 满减：整单满 X 减 Y
  - 整单折扣：按百分比打折（可设门槛）
  - 指定商品买几送几（可送同款或另一款）
- 📋 **订单记录**：搜索、查看详情、补打小票、作废；预售「标记已取货」、赊账「登记收款」
- 📊 **收银报表**：按天/周/月/自定义筛选；实收、现金/在线、赊账待收、预售待取、优惠让利、商品销量 TOP；一键导出 **CSV**（订单明细 / 商品汇总，Excel 可直接打开）
- ⚙️ **设置**：店名抬头、小票宽度（58/80mm）、份数、指定打印机、打印测试页
- 💾 **数据**：本地 `store.json`，随数据目录拷贝即迁移；可导出/导入完整备份（替换或合并）、每日自动备份（保留 30 天）、一键载入示例数据

## 小票打印（得力等热敏小票机）

- 请先安装打印机的官方 Windows/Linux 驱动，让它在系统里成为一个普通打印机
- 在「设置」里保存设置 → 「打印测试小票」，确认出纸正常
- 小票使用**窄幅纯文本**排版（中文按全角对齐），不含图片，适合串口/驱动较慢的传输，不易乱码
- 若文字被裁切/乱码：优先检查驱动里的纸张尺寸（58mm 打印纸选 58×自动/58×297），其次可调小「设置 → 保存设置」页面里的字号方案（纸宽选项）
- 收银完成会自动打印 `receiptCopies` 张；订单页可随时「补打」

## 开发

```bash
npm install        # 本机开发可设 ELECTRON_SKIP_BINARY_DOWNLOAD=1 跳过二进制
npm run dev        # 启动开发模式
npm run typecheck  # 类型检查
npm test           # 单元测试（优惠引擎等）
npm run build      # 构建 out/
```

## 打包 / 发布

本仓库通过 **GitHub Actions** 出包（本机无需装 Electron）：

- 推送到 `main`：自动跑 类型检查+测试，并构建 Windows（NSIS 安装包 + 便携版）与 Linux（AppImage + deb）产物，可在 Actions 页面下载
- 推送 `v*` tag（如 `v0.1.0`）：构建并自动发布到 GitHub Releases

本地想直接打包：`npm run dist:win` / `npm run dist:linux`（需要网络下载 electron 二进制与打包工具）。

## 数据说明

- 数据目录（设置页可查看/打开）：应用 `userData/data/store.json`
- 换电脑迁移 = 拷贝该目录，或用「导出完整备份 JSON」→ 新电脑「导入备份（替换）」
- 备份 JSON 结构带 `schemaVersion`，后续版本可做迁移

## 仓库约定

- 主进程 / 渲染进程共用类型与纯函数在 `src/shared/`（优惠引擎、金额、排版、小票、CSV 均可单测）
- 金额内部一律用「分」(整数) 计算，展示层再格式化
